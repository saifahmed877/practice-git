SocialBook is a social networking web application inspired by Facebook. It allows users to connect, share posts, interact with friends, and build online communities in a simple and interactive interface.

This project demonstrates core social media features including user profiles, posts, likes, comments, and real-time interaction concepts.

🚀 Features
👤 User registration & login system
📰 News feed / timeline for posts
📝 Create, edit, and delete posts
❤️ Like and comment functionality
👥 Friend/follow system (optional depending on build)
📸 Image & media sharing support
🔔 Notification system (if implemented)
🔍 User search functionality
📱 Fully responsive design (mobile + desktop)
🛠️ Tech Stack


Frontend: HTML5, CSS3, JavaScript / React / Tailwind CSS
Backend: Node.js / Express / PHP / Django
Database: MongoDB / MySQL / Firebase
Authentication: JWT / Session-based login
Hosting: Vercel / Netlify / AWS / Local server
